5-Axis Commissioning

Phase 1

Initial Startup

Pre-Startup Checks

Before beginning, grab the electrical fire extinguisher from Glen's office. Double-check all bus bar phasing and wire phasing in each drive. Ensure wires are securely on prepare drive.

  1. STI Module Estop (Red TapeSwitch Device): Change dip switches. G2 → G1 and M → A.
    Note Not applicable on portables.
  2. MCP Switches: Ensure switches 7 and 8 are ON. All rest must be OFF.
  3. NCU Rotary Switch: Ensure the Rotary Switch is set to 0 on front of NCU.
  4. NCU Ethernet Cables: MCP → X120, I/O → X150 (P1 or P2).
  5. Remove Magnets: From Y Pos and Z Pos Schneeberger encoders.
  6. Ring-out: Check resistances between phases on all connected motors.

NCU Initial Startup

NC/PLC Integration
  1. Load Commissioning Archive in Operate under the Setup Menu (page 2).
  2. Download PLC Project using TIA Portal v17 (a "Hardware & Software" download may be necessary depending on the version of machine).
  3. Connect directly to the X150 port on the ET200sp IO Module and assign the device name of the ET200 by right-clicking the connection in the device view of TIA Portal and selecting "Assign device name".
Disable Internal HMI
  1. Connect Bootstick USB to NCU, set Dial Switch on the front of the NCU to F and reset NCU to boot into EBoot/Setup mode.
  2. Use VNC viewer to connect to the NCU at IP Address: 192.168.214.1.
  3. Click Modify NCU Settings then click Disable Internal HMI.
    Note In parentheses next to this selection will state the active status of the internal HMI.
  4. Return the Dial Switch to 0 and reset the NCU. Now you may remove the bootstick USB.
Check alarms and Other Issues
  1. Check Operate for any missing licenses.
  2. Use Alarm List and Topology Display tabs to ensure all encoders and motors are connected correctly.
Set System Passwords
  • Default Base: SUNRISE
  • Manufacture: Tarus123
  • Service: GMServ12
  • Operator: Operator1

Customer Wi-Fi Network

Both the Tower PC and the Desk PC will need to be approved by the customer's IT Department, via the MAC address. You can find the MAC/Physical Address of the PC by opening a Windows command prompt and entering the following: ipconfig -all. Record the Physical Address of the Wi-Fi adapter (e.g. 14-D4-24-19-C9-2B) and forward this information to the Customer IT department.

Once both PCs are on the same Wi-Fi network, you may use Remote Desktop.

  3. Search Windows settings for Remote Desktop Settings and ensure it is enabled.
  4. Check PC IP Address. IP Address of tower PC must be 192.168.214.200.
Desk PC

Operate OPC/UA Configuration

After an archive has been loaded into Operate, proceed with the following OPC UA setup:

  1. Open Operate and add the OPC UA License: Access MyMachine/OPC UA (MCS314).
  2. Go to Setup (Page 2). Navigate to Network > OPC UA > Settings > Change.
  3. Company Network: Checked. System Network: Unchecked.
  4. Set Additional Network #1 address to: 192.168.214.200. (MUST match PC IP address)
  5. Set TCP Port Number: 4841.
  6. Set Message Encryption: Check all boxes (None, 128bit, and 256bit).
  7. Check "Activate OPC UA".
  8. Reboot the machine.
  9. Windows Prompt: If you receive a Windows Firewall popup/alert upon reboot (or when Operate opens), ensure you enable BOTH Private and Public networks and click "Allow".
OPC UA Connection Notes
  • OPC will only be on and connect if Operate is currently open.
  • Ensure the system time is correct, or it may fail to connect.
  • Fallback Port Change: If you need to change a port, go to the J-Mobile app on your laptop → Protocols → Look for OPC UA Client → Click the box under Configurations → Change the port number on the prompt → Press OK → Download again. You will also need to update the port number in Operate to match, which requires the machine to be power cycled to apply the port change.

Phase 3

Axis Calibration

X

X Motor Setup

Motor Feedback
  1. Ensure X1 and X2 are Active via drive parameter p105.
  2. Set Limits on Motor Feedback: Check PLC FC_Axis 1 for MeasSys1 = ON.
  3. Set Home Offset / Negative Limit
  4. Move Machine to desired negative limit.
  5. Set 34210[0] = 1
  6. Switch to RefPoint Mode and press X+ Jog. 34210 will switch to a 2 and the axis will be referenced on motor feedback
Scale Feedback
  1. Load K value into 34300[1] (e.g., 192, 332, 368, 384).
  2. Go to Encoder 2 Settings and add K value.
  3. Set MD34090 = 0.
  4. Activate RefPoint Mode and reference X by jogging. Repeat referencing to ensure numbers are counting correctly.
  5. Adjust 34320 from -1 to 1, or invert encoder in drive settings.
    Note This changes counting direction.
Set Home Offset
  1. Move to desired negative limit. Set MD34090 = value of X position.
  2. Verify Negative and Positive Limits.
Y

Y Motor Setup

Y Motor Feedback
  1. Ensure the hydraulic pump is ON. Verify Pressure/Flow set points are correct on Hydraulic IFM switch.
  2. Put starter at 1.6 and flip breaker.
  3. Put Y Carrier on crane and Activate Y Drive via p105. Watch hydraulic tank pressure to ensure pumping stops at 1180psi, and cycle pump a couple times.
Set Home Offset / Negative Limit
  1. Take down to 4-6mm from hardstop touching.
  2. Set 34210[0] to 1.
  3. Switch to RefPoint Mode and press Y+ Jog. 34210 will switch to 2 and the axis will be referenced.
  4. Ensure positive travel limit p36110 is set properly (Y Travel: -0.1 → 2400.1).
Scale Feedback (absolute)
  1. Add Measuring System 2: Setup > Drives system > Drives > Change. Hit next step until you reach Encoder settings, add Encoder 2 and finish steps.
  2. Assign Meas System 2 to Y Axis: Go to Axis assignment > Axis 2/Y. Select Encoder 2 and Measuring system 2.
  3. Set Limits on Scales: Set 34210[1] = 1, put machine into RefPoint Mode and jog positive.
Z

Z Motor Setup

Z Motor Feedback
  1. Activate Z1 and Z2 motors via p105. If the axis position is counting the wrong way, invert the counting direction in the drive system Encoder Data. If axis is moving the wrong way, change MD 32100 (1 or -1) to adjust the motor direction (requires PO Reset).
Set Home Offset / Negative Limit
  1. Take down to 4-6mm from hard stop touching.
  2. Set 34210[0] = 1.
  3. Switch to RefPoint Mode and Jog+. 34210 will switch to 2 and the axis will be referenced.
  4. Ensure positive travel limit p36110 is set properly (Z Travel: -1505.1 → +0.1).
Scale Feedback (absolute)
  1. In the PLC Project, switch to measuring system 2.
  2. Set Limits on Scales: Set 34210 = 1, put machine into RefPoint Mode and jog positive.
A&C

A&C Motors Setup

Standard limits: +/- 105.1 for A, +/- 180.1 for C. Move the A/C head by hand to confirm the correct axis is counting and in the right direction.

Portables Exception For C rotation, look at the PLC I/O tags and put that number in parameter 14510 (6).
Motor Feedback
  1. Activate motor via drive parameter p105. Move by hand to roughly 0 degrees.
  2. Turn drives ON and commutate motor angle via p1990 = 1. Do this 3-4 times to get the pole angle difference number in p1984 close to zero.
    Note If the number keeps bouncing around, you may have an encoder or phasing problem.
  3. Test A/C soft limits. If axis is moving the wrong way, alter p32100.
A/C Scales
  1. Before switching to measuring system 2 (scale feedback), move the axis to 0.00deg.
  2. Change to measuring system 2 by toggling the "[]_Axis_MeasSys1_Active" for the corresponding axis.
  3. Reference the axis by switch to "RefPoint" mode and activating a Jog+ command for the axis.
  4. Verify software limits.
S

Spindle

  1. Activate motor via drive parameter p105.
  2. Turn drives ON and commutate motor angle via p1990 = 1. Do this 3-4 times to get the pole angle difference number in p1984 close to zero.
  3. Crucial: The spindle will need to be commanded to move, either via Jog +/- or by setting a desired speed, before the drive will enable for commutation.
  4. Run at 10rpm. Ensure proper count direction (Clockwise from behind, counterclockwise in front).
  5. Find tool/tool holder to put in spindle and run up to 10,000 rpm to test full speed. DO NOT run the spindle at high RPMs without a tool or tool-holder inserted.

Machine Configuration

MD14510[0] MCP Control
  • 0 = Normal use
  • 1 = External Siemens MCP (for testing)
MD14510[1] IM Door Feedholds
  • 0 = Normal use
  • 1 = Feedhold all axes + spindle when either X142.3 or X142.4 go low.
MD14510[2] Commissioning Modes
  • 0 = Normal Use
  • 1 = All Axes Motor Feedback
  • 2 = No Head
MD14510[3] Overtemp Override
  • 0 = All non-motor OverTemps Turned Off (default)
  • 1 = All Overtemps Active
MD14510[4] Spindle Temp Offset
  • Spindle Temperature Offset in Fahrenheit (Ex: -5 means subtract 5 from active temp reading, 3 means add 3 to active temp reading)
MD14510[5] Spindle Slowdown Percent
  • Enter desired percentage of total feedrate to slow the machine down to after spindle load reaches 80% or higher. (Ex: 25 means the machine with slow down to 25% feed when triggered). By default, slowdown is 50%.
MD14510[6] C Rotation Offset
  • C Rotation Sensor Offset
  • (Ex: -500 means subtract 500 from active rotation sensor reading, +300 means add +300 to active temp reading)
MD14510[7] Chiller Status
  • 0 = i_Chiller_Status → Coolant Pressure Healthy
  • 1 = i_Chiller_Status → Coolant Flow Healthy
MD14510[8] Spindle Lighting
  • 0 = Spindle light white at all times
  • 1 = Spindle light white while idle, red while enabled
MD14510[9] RGB Lighting
  • 0 = No RGB
  • 1 = New Standard RGB Settings (Mercedes/Wenzel)
  • 2 = Honda RGB Settings (Red with Spindle on, not drives off)
MD14510[10] Lidar Config
  • 0 = Old Settings: Immediate Estop on Z3 Lidar. Z1 Audible Sound.
  • 1 = Honda Settings: 30sec Feedhold before estop on Z3 Lidar. Z1 Audible Sound.
  • 2 = New GM Settings: 30sec Feedhold before estop on Z3 Lidar. Z1 no Audible Sound, with audible sound on zone clear. Make sure only Zones 1 and 2 are on
MD14510[11] Min Safe Location
  • *Currently, only used for CF Moto*
  • Designates a “Safe area” in the X axis where the column must be in order for the Rotary Table to be activated.
MD14510[12] Max Safe Location
  • *Currently, only used for CF Moto*
  • Designates a “Safe area” in the X axis where the column must be in order for the Rotary Table to be activated.
MD14510[13] Leak Sensor Configuration
  • 0 = default, all sensors are normally closed
  • 1 = alternate, all sensors are normally open except for head leak sensor
MD14510[14] Tilt Sensor Inversion
  • 0 = default, no inversion on tilt sensor signal
  • 1 = inverted Tilt Sensor signal
MD14510[15] Tilt Sensor
  • Offset Value to offset the tilt sensor reading. (Ex: -500 means subtract 500 from active reading, 30 means add 30 to active reading)
MD14510[16] Invert Exor HW Direction
  • 0 = default (no change)
  • 1 = reverse direction
MD14510[17] Exor Pendant Config
  • 0 = Original Gen3 Remote
  • 1 = Exor X5 Wireless Pendant
MD14510[18] Leg Position Change
  • Tolerance Input the tolerance in microns (Ex: 1500 = 1.5mm tolerance) for how much movement is acceptable during the startup position check
Phase 5

Lift Tables & Weight Test

1

Lift Tables Base Configuration

Go Online & Network Setup
  1. Choose network address. Set Type of PNG/PC interface = PE/IE.
  2. Set PG/PC interface = Realtek PCIe Gbe family controller.
  3. Set First gateway = show everything.
  4. Select Targeted device = show all.
  5. Ensure IP address for your laptop is 169.254.11.# (the last octet must be higher than 10).
  6. Download the project to CU_S.
Axis Initialization
  1. Lift 1: In Parameter view, verify P10 is 0 ready and set P105 to 1. In Function view → Technology function → Basic positioner → Referencing → Absolute encoder, hit Set.
  2. Lift 2: In Parameter view, verify P10 is 0 and set P105 to 1. To reference: ensure R21905 is 0, then change R21902 from 0 → 1 → 0.
  3. Rotary: In Parameter view, verify P10 is 0 ready and set P105 to 1. In Function view → Technology function → Basic positioner → Referencing → Absolute encoder, hit Set.
Save & Test
  1. Save via the blue floppy disk icon.
  2. Go offline, Upload, Go back online, and Release E-stop to Test.
Troubleshooting Tip If having problems with Lift Tables, look at CU_S → Parameters → Function view → Input/output → Iso digital inputs. Verify DI 16 (make sure top box is green) and DI 17 (make sure top box is green).
2

Lift Tables (Motors Engaged)

  1. Retest motors and logic.
    Note If running away, check wires.
  2. Deactivate rotary (Hit E-stop, set Parameter 105 = 0).
  3. Ensure slave is roughly 2 inches higher than master. Have Mark/Dale connect the motors.
  4. Reference both motors (make sure it is E-stopped).
  5. "Hit the sticks" to drive both motors up into slots.
    Note The guys install rods into the spiral lift—whatever diameter fits the holes in the spirals—this prevents the spiral lift from spinning in place and allows it to actually drive upward.
  6. Once slave is touching, deactivate it (Hit E-stop, set P105 = 0).
  7. Drive master into the slot.
  8. Reactivate slave (Hit E-stop, set P105 = 1).
  9. Set limit to 850,000:
    • Hit E-stop.
    • Lift 1: Function view → Technology function → Basic positioner → Referencing → Absolute encoder → Set to 850,000 lu, then hit Set.
    • Lift 2: Parameter 21905 set to 850,000. Change 21902 from 0 → 1 → 0.
  10. Take pins out (Move up slowly until they come out).
  11. Have Dale level the table.
  12. Bring table down slowly until it fits into the slot.
  13. E-stop machine and Reset zero:
    • Lift 1: Function view → Technology function → Basic positioner → Referencing → Absolute encoder → Set to 0 lu, then hit Set.
    • Lift 2: Parameter 21905 set to 0. Change 21902 from 0 → 1 → 0.
  14. Take fully up to limit, make sure table is 37.500 from base then bring down to fit in pocket.
  15. Have Dale measure for shims.
  16. Reactivate rotary (Hit E-stop, set Parameter 105 = 1).
  17. Set rotary 0 (Hit E-stop. Function view → Technology function → Basic positioner → Referencing → Absolute encoder → Set 0).
  18. Go fully up.
  19. Test Rotary:
    • 90 degrees
    • 180 degrees (Bring down to make sure it fits in pockets, then take back up)
    • 270 degrees
    • 0 degrees
3

Weight Testing (r31)

Note If cutting quality is bad, look at parameter (r81).
Without Weight
  • Motor 1: Up | Down
  • Motor 2: Up | Down
  • Rotary CCW: | CW:
With Weight
  • Motor 1: Up | Down
  • Motor 2: Up | Down
  • Rotary CCW: | CW:

Crucial Action

If the Weight Test yields percentages way outside of the given baselines (e.g., Up 9.7% / Down 26.0%), call and let the assembly manager know immediately.

Portables Overview

Note Do Gen 3 set up without the EXOR remotes.

Ohm out each motor exactly like Gen 3.

Test Legs
  1. Plug into the CU32 (127 port) and go online.
  2. Open each leg and go to Rotate and Optimize.
  3. Parameter 1990: Change 0 → 1 to take the commutation angle.
  4. Parameter 1520 (High Torque): Change 3.32 → 1.32. Once hit, revert to 3.32.

  7. Use parameter 971 to save drive parameters 0-1 (Save RAM to ROM).

Misc

1

Fooke Table

Note Same general procedure as a normal lift table, but there is no rotary component.
  1. Retest motors/logic. Ensure slave is 2 inches higher than master before connecting.
  2. Reference both motors (make sure it is E-stopped).
  3. "Hit the sticks" to drive both motors up into slots.
    Note The guys install rods into the spiral lift—whatever diameter fits the holes in the spirals—this prevents the spiral lift from spinning in place and allows it to actually drive upward.
  4. Once slave is touching, deactivate it (P105 = 0). Drive master into slot. Reactivate slave (E-stop).
  5. Set Limit to 794,000 (E-stop).
  6. Take pins out. Bring table down to fit into the slot. Have Mark check.
  7. E-stop machine. Reset zero for Lift 1 and Lift 2.
  8. Take up to limit (fully up). Bring down to fit in pocket. Test.

Procedure 1

Creating an Archive in Operate

1

Archive Procedure

Purpose: This procedure outlines the correct process for creating a machine archive in Operate. Archives should always be created before and after making changes to a machine. Maintaining these backups allows technicians to compare machine configurations, restore previous settings if necessary, and improve troubleshooting efficiency.

Required Equipment: Personal USB flash drive

Procedure
  1. Open the Main Menu: From the Operate screen, select the M icon located in the upper-right corner of the display.
  2. Access the Setup Menu: Select Setup from the Main Menu.
  3. Navigate to Page 2: Once in the Setup menu, navigate to Page 2.
  4. Open the Archive Utility: Select Take an Archive. This option is located in the bottom-left corner of Page 2. (You may also select "All data of this machine").
  5. Configure the Archive: When the Archive screen appears: Verify that all available checkboxes are selected. Selecting all options ensures the archive contains the complete machine configuration, making future comparisons and restorations possible. Verify and make sure that you click the option to (Generate Archive and All Data of This Machine).
  6. Name the Archive: Enter a descriptive archive name using a consistent naming convention.
    Recommended Format Before Changes: Customer_Machine_Before_7-14-26
    After Changes: Customer_Machine_After_7-14-26
    Using a consistent naming convention makes archives easier to locate and identify.
  7. Select the Save Location: Select your personal USB flash drive as the archive storage location.
  8. Start the Archive: Verify the archive name and storage location. Select OK in the bottom-right corner of the screen to begin the archive process.
Archive Process & Completion
  • During the archive process, progress bars will begin filling until they reach 100%.
  • DO NOT power off the machine, remove the USB drive, or press Cancel. Interrupting the archive process may result in an incomplete or unusable archive.
  • While the archive is being created, the system may display "PLC Sign of Life" errors at the top of the screen. This behavior is expected because the system performs a PO Reset during the archive process and does not indicate a machine fault.
  • Once the archive has finished successfully, a confirmation message will appear indicating that the archive was completed without errors. Remove the USB drive only after this confirmation message has been displayed.
Best Practice Always create both a BEFORE and an AFTER archive whenever machine changes are made. Maintaining both archives provides a complete backup, documents configurations, allows quick restoration, simplifies troubleshooting, and supports consistent maintenance.

Procedure 3

Y & Z Axis Feedback Switching

1

Switching to Motor Feedback

Purpose: This training guide explains how to place the Y and Z axes on motor feedback using the Operate interface. It also includes the additional steps required for the Y axis when the scale encoder must be removed from the drive and axis assignment topology.

Important Safety Notes Follow all site safety procedures before jogging any axis. Use the correct variable address for the customer application before changing feedback mode. When changing Y-axis encoder topology, expect the system to perform a soft reset or NCK/PO reset. Do not interrupt the process. After completing the work, return the machine to its original scale-feedback configuration when required.
Procedure
  1. From the Operate screen, locate the M button in the upper-right corner.
  2. Press the M button to display the available menu options.
  3. Select Diagnostics.
  4. In Diagnostics, go to page 1. At the bottom of the Operate screen, select NC/PLC Variables.
  5. On the NC/PLC Variables screen, enter the appropriate variable address based on the customer application.
Variable Addresses

Ford XL, Gen3, Jumbo, and GM Gen3:

  • Y Axis: M2.2 in variable (Value 1=motor feedback, 0=scale feedback)
  • Z Axis: M2.3 in variable (Value 1=motor feedback, 0=scale feedback)

Stellantis Portable:

  • X Axis: M16.0 in variable (Value 1=motor feedback, 0=scale feedback)
  • Y Axis: M16.1 in variable (Value 1=motor feedback, 0=scale feedback)
  • Z Axis: M16.2 in variable (Value 1=motor feedback, 0=scale feedback)
  1. Enter the required bit address, such as M2.2, into the variable field.
  2. Press Change, then change the value from 0 to 1 to switch the axis to motor feedback. The axis can then be jogged using motor feedback.
Additional Y-Axis Setup Steps

For the Y axis, additional steps are required. Return to the Setup screen before continuing.

  1. To return to Setup, press the M button in the upper-right corner.
  2. After pressing the M button, select Setup from the options at the bottom of the screen.
  3. Verify that you are on page 1 of the Setup screen.
  4. Select Drive System.
  5. Go to Drive Selection.
  6. Locate and select the Y-axis drive, then select Change from the options on the right side of the screen.
  7. When prompted, continue through the settings by selecting Next until the encoder information section appears.
  8. In the encoder information section, remove the secondary encoder from the topology by setting all related options to None.
  9. Continue selecting Next until the setup is complete. The system may perform a soft reset during this process; allow it to finish. Errors may appear after completion.
  10. Next, go to Axis Assignment, select the Y axis, and remove the scale encoder by setting it to None so it is removed from the topology.
  11. When prompted, allow the required PO reset or NCK reset to complete.
  12. After the reset is complete, the Y axis can be jogged using motor feedback.
  13. To return the machine to its original configuration, repeat the same steps in reverse and restore scale feedback as originally configured.
Procedure 4

NC & PLC Reset / Firmware Recovery

1

Reset & Recovery Actions

Purpose: This procedure provides technicians with the correct method for clearing the NC and PLC memory, restoring machine archives, and performing firmware recovery on a Siemens SINUMERIK 840D control.

Warning Ensure the machine is in a safe condition before beginning. After any reset or firmware installation, verify axis limits, reference positions, and machine safety functions before returning the machine to production.
Note Always perform the NC/PLC Reset Procedure before attempting a firmware update. In many cases, the reset procedure restores normal operation without requiring firmware installation.
Procedure 1 – NC & PLC Reset
  1. Verify Startup: Power on the machine. Observe the NC 7-segment LED display. During a normal startup sequence, the display should cycle through several values before stopping at: 6
  2. Set Initial Dial Positions: Set the rotary switches to the following positions: NC Dial = 1, PLC Dial = 3. Reboot the control.
  3. Switch NC to Normal Mode: After the controller finishes booting, rotate the NC Dial from 1 to 0. Verify the following LED status: READY = Flashing Green, STOP = Flashing Orange, SF = Solid Red.
  4. Clear the PLC: Starting with the PLC dial at 3, perform the following sequence: 3 → 2 → 3 → 2. Leave the selector in Position 2.
  5. Verify PLC Reset: The controller should now display: READY = Flashing Green, STOP = Solid Orange, SF = OFF, 7-Segment Display = 6.
  6. Complete the Reset: Rotate the PLC Dial to 0. A successful reset is indicated by: READY = Solid Green, RUN = Solid Green. At this point, both the NC and PLC have been successfully cleared.
Procedure 2 – Restore the Machine Archive
  1. Once the reset is complete, load the latest machine archive.
  2. Restore all machine data.
  3. Verify that the archive loads without errors.
  4. Reference the machine if required.
  5. Test: Axis travel, Machine limits, Home positions, Machine functions.
  6. Return the machine to service only after all tests have passed.
Procedure 3 – Firmware Recovery

Only perform this procedure if the standard reset fails.

  1. Prepare the Control: Connect the engineering laptop to NCU. Insert the Siemens boot stick into the NCU USB port. The control should automatically enter Boot Mode. (No rotary switch changes should be required).
  2. Open VNC Viewer: Launch Siemens VNC Viewer. After connecting, the screen may initially appear black. Select Refresh in the upper-left corner. The NCU service interface should appear.
  3. Modify NCU Settings: Select: Modify NCU Settings. Perform a Clear or Factory Reset on each of the following: Drives, HMI, PLC, NCU. Allow each process to be completed before proceeding.
  4. Update Firmware: Open: Update Firmware. Select: Install Firmware from Boot Stick. Choose: No Recovery. Allow the firmware installation to be completed without interruption. Do not remove power or disconnect the boot stick during the installation.
  5. Restore the Machine: After the firmware update, repeat the NC & PLC Reset Procedure. Restore the latest machine archive. Reference the machine. Verify Drives, Axis motion, Limits, and PLC operation. Return the machine to production only after all verification checks have been successfully completed.
Troubleshooting Guide
  • Display does not reach "6": Boot failure. Perform firmware recovery.
  • SF LED remains ON: PLC not cleared. Repeat PLC reset sequence.
  • READY LED does not turn solid green: Reset incomplete. Repeat NC/PLC reset.
  • Firmware update fails: Incorrect firmware or boot stick. Verify firmware version and recreate boot stick.
  • Archive will not restore: Corrupt or incompatible backup. Restore a known good archive.
Procedure 5

Schneeberger Encoder Battery Replacement

1

Replacement Procedure

Purpose: This standard work instruction provides the required steps for identifying a Schneeberger encoder battery issue, replacing the encoder batteries, and documenting the service condition for training and maintenance reference.

Important Requirements The machine must always remain powered on during the battery replacement process. Use caution when removing covers and small fasteners to prevent damage or lost hardware. Follow all site-specific safety, lockout, and maintenance procedures as required before beginning work.
Procedure
  1. Review the operator diagnostics screen. Confirm the error displayed. The issue will most likely appear as an encoder error and may be shown on the Z or Y axis. Depending on the application, it may also appear on the X axis.
  2. Inspect the encoder indicator. Remove the bird cage cover and check the light indicator on the Schneeberger encoder.
  3. Evaluate the light combination. Review the indicator pattern displayed by the encoder and determine whether the battery requires replacement.
  4. Access the encoder. Locate the encoder in question and remove the rear cap. The rear cap is secured with four small Allen screws. Remove the cap carefully. Important: The machine must always remain powered on during battery replacement.
  5. Replace the batteries. After the rear cap is removed, replace the batteries. Before installation, mark the replacement date on the new battery.
  6. Verify and document the old battery condition. Check the voltage of the removed battery and record the DC voltage in the service issue notes.
Note If additional troubleshooting is required, review the encoder indicator status, confirm the axis associated with the alarm, and verify that the battery replacement was completed while the machine remained powered on.
Procedure 6

EXOR Remote Pairing Guide

1

Pairing & Troubleshooting

Purpose: This guide provides step-by-step instructions for pairing an EXOR remote with the correct mill and troubleshooting common connection issues.

Important Follow each step carefully. Incorrect machine numbers, UID information, network settings, date and time settings, firewall configurations, or firmware can prevent the remote from connecting properly.
Part 1: Pairing the EXOR Remote
  1. Set the Selector Switch: Before turning on the remote, make sure the selector switch located on the top of the remote is set to position 1.
  2. Turn On the Remote: Turn on the remote by pressing the F2 and F5 buttons simultaneously.
  3. Open the Pairing Page: Allow the remote to complete its boot-up process. Once the remote has fully booted, press K1 and K4 to access the pairing page.
  4. Select the Correct Machine: On the pairing page, select the correct machine number for the mill you are pairing with. Verify that the machine number corresponds to the intended mill before proceeding.
  5. Verify the UID and Start Pairing: Confirm that the UID (Unique Identification Number) and mill number displayed on the pairing screen are correct. Once both have been verified, select Start Pairing.
  6. Follow the Pairing LED: Locate the pairing LED on the back of the Z-slide. During the pairing process, the pairing lamp will blink between 1 and 5 times. Observe the number of times the LED blinks. When prompted by the remote, select the corresponding number of flashes.
  7. Complete the Pairing Process: Once the previous step has been completed successfully, the remote will automatically proceed to the HMI screen. The remote is now fully paired with the machine.
Part 2: Troubleshooting Guide

If the EXOR remote does not pair successfully, use the following troubleshooting steps.

1. Verify the UID
  1. Open Internet Explorer on the Main PC.
  2. Enter the following address into the address bar: https://192.168.214.11/machine_config
  3. Select System. On the left-hand side, select the Info tab.
  4. The UID number will be displayed as the first option. (Alternative: The UID may also be located on the top or side of the base station, where it is displayed on the identification label). Compare this UID with the UID being entered during the pairing process.
2. Verify the Machine Control IP Address
  1. Open Network & Internet Settings on the PC.
  2. Select Ethernet from the menu on the left-hand side.
  3. Select Change Adapter Options.
  4. Locate the network connection labeled Machine Control.
  5. Right-click Machine Control and select Properties.
  6. Select Internet Protocol Version 4 (TCP/IPv4) and select Properties.
  7. Verify the IP address. The machine control IP address should be: 192.168.214.200. If the IP address is different, it must be corrected before continuing.
3. Verify the HMI Date and Time
  1. Open Settings on the HMI.
  2. Locate and select the HMI tab near the bottom of the settings menu.
  3. On the right-hand side, select Date and Time.
  4. Compare the HMI date and time with the Main PC. Make sure both systems are synchronized.
4. Verify the Windows Firewall Configuration
  1. Open the Windows Start Menu, search for Windows Defender Firewall, and open it.
  2. Select Advanced Settings, then open Properties.
  3. When prompted, review the applicable firewall configuration.
  4. Locate the Machine Control option. Make sure there is no check mark on the Machine Control option where applicable.
5. Verify Firmware Versions
  1. The firmware version should also be checked on both the EXOR remote and the base station.
  2. The current firmware version specified for both devices is: 1.3.937
  3. Both the remote and base station should be running the appropriate firmware version. Important: Firmware updates should only be performed by an authorized Tarus employee.
Procedure 7

Spindle Encoder Errors

1

Encoder Troubleshooting

Purpose: This guide provides a structured process for troubleshooting spindle encoder errors. Follow each step in order, verify all connections carefully, and document any issues found before replacing components.

Procedure
  1. Identify the specific spindle encoder error message or code displayed. The troubleshooting path may vary depending on the error received.
  2. Open the rear cap of the Z-axis slide assembly. Inspect the cables and verify that all connectors are fully seated, secure, and properly connected.
  3. Trace the spindle communication cable back to the machine. Verify that the DB connector is wired correctly according to the applicable wiring documentation.
  4. Inspect the DB connector solder joints. Confirm that all solder joints are secure, that all wires are properly connected, and that no wires are touching or shorting against each other.
  5. Remove the rear cap of the spindle. Inspect the encoder wires leading to the resolver and verify that there are no pinched, damaged, loose, or improper routed wires.
  6. If the wiring and connections appear correct, inspect the spindle resolver. Determine whether the resolver is damaged, misaligned, or not functioning properly.
  7. If the resolver is removed or disassembled, the spindle must be commutated afterward to properly align the pole pairs before returning the machine to operation.
Important Notes
  • Always follow company lockout/tagout and electrical safety procedures before opening machine covers or inspecting electrical connections.
  • Do not replace the resolver until all wiring, connectors, solder joints, and cable routing have been inspected.
  • Record the error code, inspection results, and corrective actions taken for maintenance history and future troubleshooting.
Procedure 8

Remote-to-Receiver Board Pairing

1

Board Pairing Sequence

Purpose: This training guide provides step-by-step instructions for: 1. Pairing an old/existing remote with a replacement receiver board. 2. Re-pairing an existing remote to a receiver board.

Part 1: Pairing an Existing Remote with a Replacement Board
Step 1: Verify the Dip-Switch Configuration
  1. Open the remote to expose the small circuit board inside.
  2. Locate the dip switches on the remote and note their current positions.
  3. Open the equipment column and locate the receiver board.
  4. Verify the existing dip-switch configuration on the receiver board.
  5. Make sure you carefully record the current configuration before removing the old board.
Important When changing the dip-switch configuration on the receiver board, only use SW2. SW3 is used to determine the channel setting range. Do not change the configuration on SW3 unless SW3 has a single dip switch already turned on.
Step 2: Remove the Existing Receiver Board
  1. Locate the four screws holding the receiver board in place.
  2. Using the appropriate mini screwdriver, carefully remove all four screws.
  3. Keep the screws in a safe location so they can be reused.
Step 3: Remove the Existing Board from the Column

After removing the four screws, carefully remove the existing receiver board from inside the column.

Important: Transmitter Chip Orientation Before completely removing the board, pay close attention to the position and orientation of the small transmitter chip located on top of the board. It must be reinstalled on the replacement board in the EXACT same orientation.
Step 4: Configure the Replacement Board
  1. Locate SW2 on the replacement board.
  2. Copy the dip-switch configuration from the old board to the new board.
  3. Double-check each dip-switch position before continuing.
Step 5: Reinstall the Transmitter Chip
  1. Locate the small transmitter chip that was removed from the original board.
  2. Carefully install the transmitter chip onto the replacement receiver board.
  3. Make sure the transmitter chip is installed in the same orientation and position as it was on the original board. Verify that the chip is seated correctly.
Step 6: Install the Replacement Board
  1. Position the replacement receiver board back inside the column.
  2. Align the board with the original mounting location.
  3. Reinstall the four mini screws and tighten securely, but do not overtighten.
  4. Reconnect all wires previously removed in the correct orientation.
Part 2: Initiating the Pairing Process
Step 7: Turn Dip Switch #8 ON
  1. Remove the connector supplying power to the board.
  2. Locate dip switch #8 on SW2 and turn it ON.
  3. Confirm that the switch is fully in the ON position. Do not change the other dip-switch settings.
Step 8: Begin the Pairing Sequence
  1. Apply power to the receiver board by reattaching the connector.
  2. You will most likely see four LED lights alternating on the board.
  3. Disconnect power from the board, then reconnect it. Observe the LED lights.
  4. Continue disconnecting and reconnecting power as necessary until the board displays four solid LED lights.
Step 9: Complete the Pairing Sequence
  1. Once the board displays four solid LED lights, disconnect power from the receiver board one more time.
  2. With the power disconnected, turn dip switch #8 OFF.
  3. Restore power to the board. The pairing process should now be complete.
Part 3: How to Re-Pair an Existing Remote
  1. Open the Remote: Carefully open the remote. Expose the small circuit board located inside and locate the dip switches.
  2. Verify the Dip-Switch Settings: Check the dip-switch configuration on the remote and compare the settings with the receiver board to ensure they match.
  3. Turn Dip Switch #8 ON: Make sure the E-Stop is depressed on the remote. Locate dip switch #8 and turn it ON. Leave the E-Stop depressed while making this adjustment.
  4. Release the E-Stop: Release the E-Stop on the remote. Watch the green indicator light on the front of the remote. It should turn ON, then turn back OFF by itself. This indicates completion.
  5. Verify the Re-Pairing: Test the remote controls to confirm the equipment responds correctly.
